# Write scratch — 2026-08-11 — Convergence-hub Applications section

## Phase 1: The one sentence

> A composable agent, at the object level, **is** a small category — equivalently a directed
> container — and four independent lines of work (an internal classification of monad liftings,
> an external application in compositional active inference, a topos-theoretic generalization,
> and a boundary theorem) all reach for the single equivalence **DCont ≅ Cat**, which is
> therefore the correct object-level foundation for a theory of agent composition.

The surprising, quotable core: an **external** programme (Smithe, Topos/VERSES) reaches for
*exactly the same theorem* MacBeth uses — cited as "Famously [8]" settled background — from the
opposite end (active inference / Bayesian lenses), while composing agents by a **structurally
different** mechanism than MacBeth's Zappa–Szép weld. Convergence on the *object*, divergence on
the *composition law*.

## Genre

This is a **positioning / convergence** section, not a new-theorem paper. Spine = a thesis
("DCont≅Cat is the object-level model of a composable agent") anchored by four fronts of
already-proved / already-verified evidence. Self-contained; does NOT depend on the open
State-completeness lemma. Reusable as grant Applications narrative + book Applications section.
