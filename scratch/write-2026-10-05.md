# Write scratch — Cartan-boundary note — 2026-10-05

## Phase 1: The one sentence
> Tangent vectors on finite-support polynomial functors have no additive inverses — the
> tangent fibers are free ℕ-modules on holes, not ℤ-modules — so (SPoly, ∂) carries no
> scalar ring object and the Aintablian–Blohmann Cartan calculus does not descend; only
> the subtraction-free ℕ-scalar fragment survives.

The surprise: existence + uniqueness of ∂ are banked, so one expects the whole
differential-geometry tower to follow. It does not. The rig ℕ is a hard ceiling at
exactly the point where forms/Lie-derivatives need −1. Same subtraction-free knife as
the uniqueness converse.
