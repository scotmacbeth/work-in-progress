# M2b: comonad ⟹ directed container (the CONVERSE)

## Target
From a comonad structure on `Ext C` (counit ε, comult δ, three laws) recover the
directed-container ops (root, sub, shift) and prove D1–D5. Dual to forward (Directed.lean).

## Represented data (justified by representation theorem in Basic.lean)
ε natural `Ext C ⟹ Id`  ⟺  `e : (s) → Pos s`,  ε⟨s,v⟩ = v (e s).
δ natural `Ext C ⟹ Ext C∘Ext C` ⟺ `σ : S→S`, `τ : (s)→Pos(σ s)→S`,
  `w : (s)→(p:Pos(σ s))→Pos(τ s p)→Pos s`,
  δ⟨s,v⟩ = ⟨σ s, fun p => ⟨τ s p, fun q => v(w s p q)⟩⟩.

Structure `ContainerComonad extends Container`: fields e, cShape(σ), cSub(τ), cVal(w).
counit/comult defined as above. `IsComonad` = three genuine comonad law equalities.

## The linchpin: σ = id   (cShape s = s)
From RIGHT counit `Ext.map ε ∘ δ = id`: take shapes.
Eval at X:=Pos s, ⟨s,id⟩.  (Ext.map ε (δ⟨s,id⟩)).1 = cShape s ;  id.1 = s.  ⟹ cShape s = s.

## Once σ=id, the laws collapse to D1–D5 (dual of forward):
- LEFT counit  ⟹ D1 (cSub s (e s)=s) + D2 (w s (e s) q = transport q).
- RIGHT counit ⟹ D3 (w s p (e(τ s p)) = p).   [shape part = σ=id]
- COASSOC      ⟹ D4 (τ(τ s p) q = τ s (w s p q)) + D5.

## Recovery `toDirectedContainer (h : M.IsComonad) : DirectedContainer`
- root s := M.e s
- sub  s p := M.cSub s ((hcs s).symm ▸ p)      where hcs s : cShape s = s
- shift s p q := transport of M.cVal s _ _ ...
Transports unavoidable (cShape s ≠ s definitionally; occurs-check blocks subst).

## KEY TECHNIQUE for transports
State transport helper lemmas with FREE variables a b : S, h : a = b, prove by `cases h; rfl`,
then INSTANTIATE at a := cShape s, b := s, h := hcs s. (Same trick as Ext.ext_eq's free s₁ s₂.)

## KEY SIMPLIFICATION (found after S1): `comult_norm`
Prove ONCE: comult⟨s,v⟩ = ⟨s, fun p=>⟨rSub s p, fun q=>v(rShift s p q)⟩⟩ via Ext.ext_eq (cShape_eq).
Absorbs ALL cShape transport. Then D1–D5 mirror FORWARD proof backwards (only D1/D4 transports):
- D1: rSub s (e s)=s   from LEFT counit + mk_inj  (NO transport, defeq)
- D2: rShift s (e s) q = d1▸q  from LEFT counit value (proof-irrel)
- D3: rShift s p (e(rSub s p))=p  from RIGHT counit value (NO transport)
- D4: rSub(rSub s p) q = rSub s (rShift s p q)  from COASSOC (nested mk_inj)
- D5: from COASSOC deepest value (D4 transport, same as forward)
Helpers: `cast_symm_cast` (g.symm ▸ (g ▸ x) = x, by cases g), `mk_inj` (Sigma eq → shape eq + transported val eq, by injection+subst+eq_of_heq).
S1 cShape_eq: DONE, compiles (congrArg Sigma.fst on right_counit probe).
