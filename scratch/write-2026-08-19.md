## The four moves (from WRITE.md), + honesty
1. Reframe: shapes must be OBJECTS/vertices, positions = hom-objects per ORDERED PAIR.
   One f.d. vspace $P_{a,b}$ per $(a,b)\in S\times S$.
2. Matrix $\odot$: $(P\odot Q)_{a,c}=\bigoplus_b P_{a,b}\otimes Q_{b,c}$, unit
   $I_{a,b}=\fld\cdot[a{=}b]$. The $\bigoplus_b$ = composable-arrows sum = the RIGHT
   reincarnation of the extensivity coproduct whose absence caused the collapse.
   HONESTY: right reincarnation, NOT literally the same $\coprod$.
3. Monoid = algebroid (Bénabou); comonoid via fibrewise op = algebroid (both ops
   cancel; variance guardrail = arXiv:1704.00329).
4. Strict $\lhd$ = DIAGONAL degeneration. Embed single-index $(S,(P_s))$ as diagonal
   matrices $P_{a,b}=\delta_{ab}P_s$. Then $\odot$ restricts to pointwise
   $(P_a\otimes Q_a)$; (co)monoids = family of algebras = §7's
   $\mathrm{Comon}_\lhd(\Fam(\Vec_{fd}^\op))\cong\Fam(\Alg_\fld^\op)$.
   TWO coupled diagonalisations, ONE phenomenon:
     (i) position-support diagonal (embedding, $P_{a,b}=0$, $a\ne b$);
     (ii) §6's counit-FORCES-the-comult-shape-map to the diagonal.
   Subtlety to flag honestly: strict $\lhd$ has shape set $S\times S$ not $S$; the
   counit (ii) is exactly what pins a single-index comonoid back onto the diagonal,
   so its comonoid theory coincides with the diagonal-matrix comonoid theory.
5. Single obstruction stated once: strict collapse (objects $\Id^N$, morphisms not
   full, comonoids = family of algebras) all driven by $\Vec$ non-extensive
   ($\coprod\subsetneq\bigoplus$, Carboni–Lack–Walters 1993). Algebroid reappears
   precisely when matrix $\odot$ restores $\bigoplus_b$.
