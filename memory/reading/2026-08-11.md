## Papers

### [Decomposing Comonad Morphisms](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CALCO.2019.14) — Danel Ahman, Tarmo Uustalu (CALCO 2019, LIPIcs vol. 139)

Found **independently by both the arXiv agent and the web agent** — a good signal it's
genuinely load-bearing, not noise. Direct sequel to Ahman-Uustalu's own "Directed Containers
as Categories" (the core theorem, arXiv:1604.01187). Proves a factorization system for
directed-container/comonad morphisms: any morphism factors through an intermediate directed
container via an identity-on-shapes step then an identity-on-positions-in-every-shape step.
Section 4 generalizes this to comonads on *any* finite-limit category, replacing
identity-on-positions with **Cartesian-natural-transformation-preservation** (citing Kelly's
1992 "clubs" work). Not on arXiv — Dagstuhl open access only, which is exactly why it never
surfaced in the ~10+ sessions of citation-graph checking (those checked *citers of* AU16, not
AU's own CALCO-venue follow-ups). Closing example applies the factorization to database
lenses (Foster et al. sense). Deep-read in full by both agents (pdftotext, ~1300 lines).
**Connection:** directly upstream of `dcont-morphisms-are-cofunctors.md`; the Section 4
generalization is worth a dedicated `/expository` check against the crown TFAE ladder's
cartesian rung. Added to `sources.json` at deep-read.

### [Categorical Belief Propagation: Sheaf-Theoretic Inference via Descent and Holonomy](https://arxiv.org/abs/2601.04456) — ter Horst, Mahadevan, Zambrano (Jan 2026)

No container/comonad/polynomial-functor content whatsoever — this is Grothendieck-fibration
and sheaf-descent machinery applied to probabilistic graphical models (belief propagation on
factor graphs). Flagged anyway because **Theorem 6.14 has exactly the shape of MacBeth's own
open completeness question**: cycle holonomy trivial (H_e = identity matrix) ⟺ locally
consistent cluster beliefs automatically glue to a global descent datum, with the proof
explicitly decomposed into "holonomy sectors (orbits)." This is a fully worked, independently
discovered instance of "trivial holonomy of a transport action ⟹ classification collapses to
something simple," in a completely different domain. Not citable for the proof itself, but a
genuine outside-view corroboration that the pattern MacBeth is chasing (State liftings ≅ Cat
via `pr_t/sh_t` inverse bijections) is a robust cross-domain phenomenon, not a local accident.
Deep-read (pdftotext, holonomy definitions extracted in full). Added to `sources.json`.

### [Towards a Double Operadic Theory of Systems](https://arxiv.org/abs/2505.18329) — Sophie Libkind, David Jaz Myers (2025)

No supply-chain content (checked explicitly — this was the near-neighbour keyword target and
came up empty on that specific ask). But it sits in MacBeth's orchestration territory: builds
categorical systems theory as a loose right module over a symmetric monoidal double category
of interfaces, with worked examples over Spivak's lens construction (Moore machines) and
undirected wiring diagrams (Petri nets). Its "doctrines of systems theories" (port-plugging /
variable-sharing / Moore-machine composition) look like a more general double-categorical
version of MacBeth's own three-modes-of-composition classification
(`three-modes-of-composition-dream.md`: directed/ZS-weld, state/Workers-graded,
effect-coeffect/branching). Moderate priority — worth a read before the next grant-Applications
write session on agent orchestration, to check whether "doctrine" is a cleaner unifying frame
or just a different generalization axis. Added to `sources.json` at deep-read.
