## Papers
### [Graded Hoare Logic and its Categorical Semantics](https://arxiv.org/abs/2007.11235) — Gaboardi, Katsumata, Orchard, Sato (2020/2021)
New to sources.json (agent-summary, abstract + search-level full text). Introduces **graded Freyd
categories**: an M-graded category over a cartesian base (M a preordered monoid), with a lifting
function lifting pure computations into the unit grade; trivial M collapses to an ordinary Freyd
category. Cites Atkey's parameterised-monad/Freyd lineage directly — same family tree as the
Atkey ENTCS-229 result MacBeth's arrow-category theorem now cites. **Different axis than
MacBeth's branching-collapse**: this M grades effect *size/cost* on top of an already-Freyd base
category; MacBeth's non-branching condition is about whether the base monad itself admits the
arrow/closed-indexed-Freyd structure at all. Not competing — citable as established "graded Freyd
category" vocabulary if the arity-graded-Atkey framing ever gets written up.

### [A Category-Theoretic Framework for Dependent Effect Systems](https://arxiv.org/abs/2601.14846) — Kura, Gaboardi, Sekiyama, Unno (2026-01-21)
New to sources.json (agent-summary). Introduces **indexed graded monads** — families
`T_I : M_I × E_I → E_I` indexed over a base category, with both the effect functor and its
grading pomonoid varying with the index — for dependent-effect refinement types. Grepped in full
for Freyd/arrow/Atkey/indexed-Freyd content: none found. Adjacent 2-categorical graded-monad
machinery (indexed × graded, the same "cross two axes" move as κ:GT⇒TG) but orthogonal to the
Freyd/arrow story.

### Standing watch — Vollmer, Paviotti, Orchard, "On the Category of Graded Monads" (CT2026 talk)
Two agents (arXiv + web) independently confirmed the talk is real (CT2026 program, Baltimore,
12–18 July, already run) but **still not posted to arXiv** as of this session. The web agent
obtained the **full abstract** for the first time (previously only paraphrase-level in feeds.md):
`Gmd : MonCat × 2Cat → 2Cat` sends `(I,κ) ↦ [BI^op,κ]_lax`; Gmd is itself a graded monad on 2Cat;
dual `Gcmd(κ) = [BI^op,κ]_oplax` handles graded comonads; the talk gives "equivalences for
distributive laws for graded monads and graded comonads in the style of Power and Watanabe
[2002]," explicitly contrasted with Gaboardi et al. 2016. This is a genuine 2-categorical general
account of exactly MacBeth's κ:GT⇒TG question, at the graded (not yet arity-instantiated) level —
worth a dedicated read the moment it lands on arXiv.

### MDPI (non-arXiv) — "Zappa–Szép Skew Braces: A Unified Framework for Mutual Interactions in Noncommutative Algebra" (Mathematics 14(2):215, 2026)
