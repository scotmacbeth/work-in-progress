## Genuinely new (survived cross-check)

1. **[Catala GitHub issues #1095 & #1096](https://github.com/CatalaLang/catala/issues/1095)**
   (filed 2026-09-02, open, zero comments) — a real, fresh compositional-semantics bug in the
   `catala-examples` executable encoding of US tax code §121 (home-sale gain exclusion): the joint
   -return scope's `person2` sub-scope reads `person1`'s usage-period data at line 114-115
   (issue #1095), and a *second, structurally independent* instance of the same person1-centric
   asymmetry recurs at lines 216-220 (issue #1096) — so the naive one-line fix does not restore
   symmetry. This is a concrete instance of the grant's "compositional correctness has economic
   consequences" narrative: a scope meant to be parametric/symmetric in which spouse occupies which
   slot silently breaks that symmetry at two independent wiring sites. Worth reading the actual
   diffs if this becomes a `/write` or `/expository` worked example.
2. **[Catala GitHub issue #691](https://github.com/CatalaLang/catala/issues/691)** ("Contract
   language for Catala scopes," open since 2024-09, most recent activity 2026-01-14) — proposes
   Hoare-style `requires`/`ensures` sugar over Catala's overloaded `assertion` construct, splitting
   runtime-check / test-oracle / verification-hypothesis into a real pre/postcondition contract
   language for scopes; unresolved open question about interaction with variables that have
   multiple states across a scope's lifecycle. Not categorical, but the closest thing found so far
   to formal specification-of-composition activity happening natively inside Catala.
3. **[cstheory 55588](https://cstheory.stackexchange.com/questions/55588/)** — open (0 answers,
   score 5, created 2025-07-24, last activity 2026-08-05): asks for the relational-parametricity
   proof that `∀A.((A→A)→P)→Q ≅ P→Q`. This is exactly the Church-encoding / initial-algebra-of-`1+X`
   shape — a free-theorem argument that naturality in `A` forces the map to factor through
   evaluation at `id`. A genuinely open question that MacBeth's container/polynomial-functor
   vocabulary could plausibly answer directly (not urgent, but a candidate "answer a real open
   question in public" opportunity, unlike most forum finds which are just background reading).
