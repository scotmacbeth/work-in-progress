### [Data Types as Quotients of Polynomial Functors](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ITP.2019.6) — Avigad, Carneiro, Hudon (ITP 2019)
**No arXiv ID exists** — proceedings-only, DOI `10.4230/LIPIcs.ITP.2019.6`, Lean repo
`github.com/avigad/qpf`. Confirmed via multiple independent searches. Content (reconstructed from
WebSearch snippets and slide decks — the arXiv agent's WebFetch could not extract the PDF text
cleanly, so this is **floor-level agent-summary, not a verified read**): uses container-style
shape/position polynomial functors (`A ▷ B` notation), example `list α ≅ Σ n:nat, fin n → α`. QPF

for Path 6: this is prior art for exactly the "quotient container" pattern our Mathlib program would
need. **Top priority next session: proper `download_pdf` + local pdftotext read** before citing any
technical claim from it — added to sources.json at agent-summary, explicitly flagged as unverified.
