[[cohomological-obstruction-family]] work is built on, tied to strict factorization systems. This is
Danel Ahman's own paper (a core Path-2 author MacBeth already cites for D1–D5), not a third party — so
this is almost certainly the *source* of the ZS-in-Poly connection rather than an independent scoop, but
**it needs a direct full read before any further claim of novelty on the core ZS/distributive-law
story** (per the standing "READ POLY BEFORE CLAIMING" rule). Could not extract text this session; no
arXiv ID found (personal-site PDF only) — not added to sources.json pending confirmation of a

### [Autodiff through function types: Categorical semantics the ultimate backpropagator](https://julesh.com/posts/2026-02-20-categorical-semantics-ultimate-backpropagator.html) — Jules Hedges, Feb 2026
Shows the category of "additive lenses" is cartesian closed because commutative monoids have biproducts

Punchline: using function types as a learning parameter space just re-derives ordinary deep learning
with overhead — a useful cautionary companion data point for the Vec-container "uses" write-up. Strong
candidate citation.
