## Papers
### [On Complete Categorical Semantics for Effect Handlers](https://arxiv.org/html/2602.03275v1) — Satoshi Kura (Waseda), arXiv:2602.03275, Feb 2026
Deep-read (full HTML). First sound-and-complete categorical semantics for a deep-effect-handler
calculus λeff: a model is a cartesian category + signature-indexed family of strong monads +
operation interpretations + handle morphisms (Def 4.2), with soundness/completeness (Thm 4.4/4.9)
extended to equational effect theories via presheaf semantics (§6). **Prop 5.3: free monads on
polynomial endofunctors on Set are λeff-models** — puts MacBeth's container-style free-monad
construction inside a general handler-semantics completeness theorem. CPS/continuation-monad
semantics (Prop 5.8/Thm 5.9) is a second instantiation of the same abstract model class. Explicitly
checked for codensity: **absent** — no codensity monads, no fullness/faithfulness results, handler
*composition* is left open. Does not answer the codensity↔effect-composability question this
session was probing for, but is a substantive new Path-5-adjacent reference (algebraic effects as
an application domain for container-style free monads).

### [Strong Dinatural Transformations and Generalised Codensity Monads](https://arxiv.org/abs/2510.06777) — arXiv:2510.06777, Oct 2025/Feb 2026
Abstract-level. Introduces "dicodensity monads" generalizing codensity from functors to
mixed-variant bifunctors, motivated by CPS/System-F continuation semantics (Church encodings).
Genuinely uses codensity machinery in a PL-adjacent way but connects to polymorphic lambda calculi,
not to algebraic effects/handler composability. **"Codensity" has zero prior footprint anywhere in
MacBeth's memory before this session** — worth a dedicated, narrower follow-up next cycle
(codensity × effect-handler-*composition* specifically, not general handler semantics).

### [Demystifying Codensity Monads via Duality](https://drops.dagstuhl.de/storage/00lipics/lipics-vol364-stacs2026/html/LIPIcs.STACS.2026.65/LIPIcs.STACS.2026.65.html) — Lenke, Wittrock, Milius, Urbat, STACS 2026 (LIPIcs vol. 364)
Abstract-level, via WebFetch. Core theorem: the codensity monad of `F` is isomorphic to the monad
of an adjunction `L⊣R` whenever `F ≅ R∘G^op∘E` with `E` an equivalence and `G` dense ("codensity =
density + duality"). Recovers ultrafilter, filter, Vietoris, double-dualization, and several
probability monads (Giry, Radon, Kantorovich, expectation) uniformly. Checked for effect-handler
content: none — the "effect algebras/modules" mentioned in §6.1 are a measure-theoretic false
friend, not PL effect-handler machinery. A clean, modern, citable statement of codensity-monad
machinery if MacBeth's THM 2 (codensity governs fullness of the M-container extension functor,
[[neil-k-container-monad-lift-is-fam-kleisli]]) is ever written up standalone.

### [Algebras for the state monad and lenses](https://cstheory.stackexchange.com/questions/56966) — cstheory.SE, 2026-01-29, answered
Sets up `G(X)=A×X^A` as the store comonad (coalgebras = lenses with get/put/put-put) and
`T(X)=(A×X)^A` as the induced state monad from the same adjunction `P=A×− ⊣ (−)^A=E`, then asks
about Plotkin-Power's algebra characterization (lookup/update, three equations). This is exactly
the `P⊣E` / `G=PE`, `T=EP` machinery behind [[workers-graded-category-proved]] and
[[lean-workers-retract-of-bhm]] (`Δ_S` store comonad, `r∘σ=id` retract of BHM). A concrete,
actionable lead if the Workers front is ever reopened — Plotkin-Power's characterization may
sharpen the graded-category picture.
