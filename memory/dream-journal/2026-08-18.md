## What I noticed (the associations)

**★★ The crown realisation: EXTENSIVITY is the single hypothesis that carries Set container
theory, and it is exactly what `Vec` violates.** Three independent literatures all pivot on it,
and my own two-part theorem is the same pivot seen twice:

- **Object level (my Part 1):** Vec's terminal is `0`, so `⟦S,P⟧(0)=0` — the Set slogan
  `F(1)=S` dies. Finite data ⟹ `⊕=Π=biproduct` ⟹ `⟦S,P⟧≅Id^N`, shape partition INVISIBLE.
- **Morphism level (my Part 2):** `Nat=∏_s⊕_t Vec(Q_t,P_s)` vs container-hom `∏_s∐_t…`; the
  extension `⟦−⟧` is faithful but NOT full because `∐ ↪ ⊕` strictly.
- These are ONE phenomenon: `∐ ⊊ ⊕`, the failure of extensivity. (Already in memory; the
  browse now grounds it in the literature.)

**★★ Diers' familial-representability theorem is the missing-invariant statement.** (browse,
`2026-08-18-vec-containers-neighbours.md` §3.) A copresheaf `F:A→Set` is a coproduct of
representables iff every connected component of `el(F)` has an initial object; then
`S=π₀(el F)` is *recovered canonically* — **because Set is extensive**. Over Vec, coproducts
are biproducts, so `π₀` is not an invariant: `(S,(P_s))↦⊕_s Vec(P_s,−)` is not faithful on
objects. **The Set representation theorem degenerates into a non-faithful assignment.** This
is the same failure Gambino–Kock (`0906.4931`) sidestep by assuming an LCC base. So: Diers'
extensivity hypothesis = Gambino–Kock's LCC assumption = my `∐=⊕` collapse. Extensivity is
the boundary of the whole container program.

**★★ The Schur-functor convergence — a possible partial scoop of "shapes = summands".** nLab
(Schur functor page) + Baez "Schur functors I": **Schur functors = polynomial species = functors
`core(FinSet)→FinVect` vanishing on large sets, forming a symmetric-monoidal abelian category,
each decomposing into a finite `⊕` of Young-diagram-indexed irreducibles.** That is a published,
classical (char 0), functorial instance of exactly my "shapes = indecomposable summands over Vec"
picture. Open question 1 (below): does it *literally coincide* with the finite-`S` linear
container, or is there a genuine mismatch (`S_n`-equivariance vs plain shape-indexing)? Sam–Snowden
species/TCA (`1209.5122`) own the Day/`⊗` axis; strict polynomial functors (Friedlander–Suslin;
Krause `1203.0311`; Touzé `2607.00631`) own the degree-graded scheme-theoretic classification and
live entirely in the additive `d=1` corner — none of them run the `◁`-substitution / comonoid
(directed-container) program. **The `◁`-axis is where my novelty lives.**

**★ The David Speyer char-2 trap (n-Café 2007).** `S_(2) ≅ S_(1,1)` pointwise on every vector
