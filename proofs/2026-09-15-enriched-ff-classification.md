# Classification: when is Neil's self-enriched M-container extension fully faithful?

**MacBeth (Kodamai). 15 September 2026. PROVE session.**
**Answers Neil UID 168. CC Robin. Grade: proved (line-audited below).**

---

## Problem

Let `M` be a **commutative strong monad on `Set`**. By Kock, its Kleisli category
`Kl(M)` is symmetric monoidal with tensor `A ⊗ B = A × B` on objects and monoidal
unit `I = 1` (the terminal set). Consider Neil's self-enriched `M`-container extension

    ⟦S,P⟧ = Σ_s [P_s, −] : Kl(M) → Kl(M)          (construction (C) of the reconciliation note)

which is available exactly when `Kl(M)` is monoidal **closed**, and (by flagship **T1**,
`containers-over-a-base.tex` §T1) is **fully faithful iff the monoidal unit `I=1` is
connected**, i.e. `Kl(M)(1,−)` preserves small coproducts. Define

    𝒞ℒ = { M : Kl(M) is symmetric monoidal closed }        (Kock: each [A,MB] free)
    𝒰𝒩 = { M : the monoidal unit 1 of Kl(M) is connected } (Kl(M)(1,−) preserves small coproducts)
    TARGET = 𝒞ℒ ∩ 𝒰𝒩  =  { M : Neil's enriched extension is fully faithful }.

**Conjecture (PROVE.md):** TARGET contains no genuinely effectful monad; the only
inhabitants are `Id` and idempotent/localization monads.

---

## Theorem (sharp classification)

> **`𝒞ℒ ∩ 𝒰𝒩 = { Id }`** (up to isomorphism of monads).
>
> Equivalently: *Neil's self-enriched `M`-container extension over a commutative-monad
> base `Kl(M)` is fully faithful if and only if `M` is the identity monad.* No nontrivial
> effect — including every nontrivial idempotent/localization monad — qualifies.

This **confirms and sharpens** the conjecture: the answer is not merely "no effectful
monad" but literally *only the identity*. The idempotent monads floated as candidate
inhabitants are excluded because (Corollary 3) no nontrivial idempotent monad on `Set`
lies in `𝒰𝒩`. It is a **sharp negative answer to Neil's hope** that enrichment is a
preferable setting for a *uniform* full-and-faithfulness theorem: uniform enriched f&f
over a Kleisli base is available for no effect at all.

## Preliminaries (all standard, cited)

**(P1) Kleisli tensor and unit.** For commutative `M`, `Kl(M)` is symmetric monoidal
with `A⊗B = A×B` on objects, `F:Set→Kl(M)` strict monoidal, unit `I = F1 = 1`. [Kock,
*Closed categories generated by commutative monads*, J. Austral. Math. Soc. 12 (1971)
405–424; recorded in scratch note §1, grade proved(standard).]

**(P2) Global points.** `Kl(M)(1, X) = Set(1, MX) = MX`, naturally in `X∈Kl(M)`. So the
unit's global-points functor `Kl(M)(1,−)` is (carried by) `M` itself. [Immediate.]

**(P3) Coproducts in `Kl(M)`.** `F:Set→Kl(M)` is a left adjoint, so preserves coproducts;
coproducts in `Kl(M)` are the `Set` coproducts (disjoint unions) on objects, with the
`Set` injections composed with `η`. Hence `Kl(M)` has all small coproducts. Copowers:
`T·Z = ∐_{t∈T} Z = T×Z` on objects. [Standard.]

**(P4) Kock's closedness criterion.** For commutative `M`, `Kl(M)` is monoidal closed iff
for all sets `A,B` the function set `(MB)^A` is a free `M`-algebra, i.e. `(MB)^A ≅ M[A,B]`
naturally for some `[A,B]`; then `[A,−]` is right adjoint to `(−)⊗A = (−)×A`. [Kock; scratch
note §1, proved(standard).]

**(P5) Definition of connected.** `containers-over-a-base.tex`, Def. (line 336): the unit
`I` is *connected* iff `C(I,−):C→Set` preserves **small coproducts**. Via (P2) this reads:
`M` preserves small coproducts (as a `Set`-endofunctor). [Definition.]

## Proof

### Step 1 — `𝒰𝒩` forces the writer functor form.

Let `M ∈ 𝒰𝒩`. By (P2)+(P5), `M` preserves small coproducts. We extract the exact shape.

Write `E := M1`. For any set `T`, the copower `T·1 = T` (P3), and the coproduct-comparison
map that connectedness makes invertible is, at `Z = 1`,

    θ_T : T × M1 ⟶ MT,      θ_T(t, e) = M(ι_t)(e),   where ι_t : 1 → T picks out t.

Indeed `θ_T` is the assembly of the `T` injections `M(ι_t) : M1 → MT` over `t∈T`; it is the
canonical map `∐_{t∈T} Kl(M)(1,1) → Kl(M)(1, ∐_{t∈T} 1)`, i.e. the copower-comparison of
(P5) at the object `Z=1`. Connectedness makes every such comparison a bijection, so

    θ_T : T × E  ≅  MT     for every set T,          (★)

and `θ` is natural in `T` (naturality of the injections). Moreover `θ_1 = id_{M1}`. Thus

    **θ : (−) × E  ⟹  M  is a natural isomorphism**;   the underlying functor of M is the
    writer functor `WriterE = (−) × E`, with `E = M1`.

*(This uses only preservation of copowers `T·1`, a special case of (P5); the conclusion is
therefore robust even to the T1 open gap "copowers vs. all coproducts" — see Remark 1.)*

By the standard classification of monad structures on `(−)×E` (naturality forces
`η_X(x) = (x, e₀)` and `μ_X(x,e,e') = (x, m(e,e'))` for a fixed element `e₀∈E` and map
`m:E×E→E`; the monad laws are exactly the monoid laws), `M` is the **writer monad** on the
monoid `(E, m, e₀)`, and commutativity of `M` ⟺ commutativity of `E` [Kock]. Hence:

> **Lemma A.** `𝒰𝒩 = { writer monads on commutative monoids }`, with `E = M1`.
> (Conversely every writer monad preserves all small coproducts, since `×` distributes over
> `∐` in `Set`, and is commutative iff `E` is; so both inclusions hold.)

### Step 2 — `𝒞ℒ` forces `E ≅ 1`.

Let `M ∈ 𝒞ℒ ∩ 𝒰𝒩`. By Step 1, `MX ≅ X × E`. Closedness (P4) requires, in particular, that
`(−)⊗A = (−)×A` have a right adjoint for the object `A = ∅ ∈ Kl(M)`. Compute its would-be
adjoint value on any `B`:

    Kl(M)(C ⊗ ∅, B) = Kl(M)(∅, B) = Set(∅, MB) = 1     for every C,

so the representing object `[∅,B]` satisfies `Kl(M)(C, [∅,B]) ≅ 1` for all `C`; i.e.
`[∅,B]` is a **terminal object** `⊤` of `Kl(M)`. A terminal object `⊤` satisfies
`Set(C, M⊤) = Kl(M)(C,⊤) ≅ 1` for all `C`, forcing `M⊤ ≅ 1`. Using the writer form (★):

    ⊤ × E  ≅  M⊤  ≅  1     ⟹    |⊤|·|E| = 1     ⟹    E ≅ 1.

Therefore the underlying functor of `M` is `(−)×1 ≅ Id`, and the unique monad structure on
`Id` gives `M ≅ Id` as a monad. ∎ (⊆)

### Step 3 — `Id ∈ 𝒞ℒ ∩ 𝒰𝒩`.

`Kl(Id) = Set`, which is cartesian closed (hence symmetric monoidal closed), so `Id ∈ 𝒞ℒ`.
Its unit `1` is connected: `Set(1,−) = Id` preserves all coproducts, so `Id ∈ 𝒰𝒩`. By T1,
Neil's extension `Σ_s [P_s,−] = Σ_s (−)^{P_s}` over `Set` is the classical Abbott–Altenkirch–
Ghani container extension, which is fully faithful (T1, `1` connected). ∎ (⊇)

Steps 2–3 give `𝒞ℒ ∩ 𝒰𝒩 = {Id}`. ∎

## Corollaries

**Corollary 1 (independence of the two axes — 2×2 table).** Each cell is inhabited by a
commutative strong monad, so `𝒞ℒ` and `𝒰𝒩` are logically independent and their
intersection is as small as possible.

| | **connected (`𝒰𝒩`)** | **disconnected** |
|---|---|---|
| **closed (`𝒞ℒ`)** | `Id` *(TARGET)* | `Reader (−)^S`, `|S|≥2`; also `Maybe/Par`, `Powerset/Rel` |
| **not closed** | `Writer_E`, `E` nontrivial comm. monoid | `Dist` (finite distributions); `List` etc. |

Witnesses verified computationally (`scratch/check_un_cl.py`):
- **Reader** `(−)^S`: closed (CCC, scratch-note table), but `(A+B)^S ≇ A^S+B^S` for `|S|≥2`
  — *disconnected*. (`M1 = 1^S = 1` is a red herring: connectedness is coproduct- not
  terminal-preservation.) Reader is the pivot: closed, so Neil's extension *exists*, yet
  *not* full because its unit `(−)^S` is disconnected. Matches THM2 (reader not codense).
- **Writer_E**: connected (`× ` distributes over `∐`), but `Kl(Writer_E)` has **no terminal
  object** when `E≇1` (`M⊤ = ⊤×E ≅ 1` is impossible) — *not closed*.
- **Maybe/Powerset**: closed (Par / Rel), but `M∅ = 1 ≠ ∅` — *disconnected*. (Their
  terminal object is `∅`, with `M∅ = 1`; connectedness would demand `M∅ = ∅`.)
- **Dist**: neither (product-of-simplices non-closure; support can straddle a coproduct).

**Corollary 2 (`𝒞ℒ`'s two ways to have a terminal object, and why only `Id` survives).**
For `M∈𝒞ℒ` the terminal object `⊤` of `Kl(M)` has `M⊤≅1`, and either `⊤=1` (then `M1≅1`,
"affine at the point", as for Reader, Dist, Id) or `⊤=∅` (then `M∅≅1`, "pointed", as for
Maybe, Powerset). Connectedness kills the second case (`M∅=∅`) and, via the writer form,
collapses the first (`1×E≅1 ⟹ E≅1`). The join of the two constraints leaves only `Id`.

**Corollary 3 (idempotent monads are not in `𝒰𝒩`, except `Id`).** A nontrivial idempotent
(localization) monad `L` on `Set` corresponds to a nontrivial reflective full subcategory
`𝒟 ⊊ Set`. `L = i∘R` with `R⊣i` the reflector; `i` (a right adjoint) does not preserve
coproducts, and indeed by Lemma A membership in `𝒰𝒩` forces `L` to be a writer monad, which
is idempotent only when `E≅1` (writer_E idempotent ⟺ `m:E×E→E` iso to a point ⟺ `E=1`).
Hence the only idempotent monad in `𝒰𝒩` is `Id`. *This refutes the conjecture's suggestion
that nontrivial idempotent monads inhabit TARGET — they inhabit `𝒞ℒ`-adjacent territory but
fail connectedness.* (Direct check: the terminal monad `L X = 1` and the subsingleton
reflection have `L(1+1)=1 ≠ L1+L1=2`.)

## Verdict for Neil (the reconciliation, completed)

The three-functor picture of the scratch note now has a *complete* classification on the
enriched leg (C):

- **Availability** of construction (C) = `𝒞ℒ` = base closed = Kock's exponential-ideal
  condition. Reader, Maybe, Rel, Vec, Cat, Set, idempotents are available; Dist, `β`,
  continuation, list are not.
- **Full faithfulness** of (C) = `𝒞ℒ ∩ 𝒰𝒩` = **`{Id}`**.

So Neil's enriched-Yoneda formula `Nat(Σ_s[P_s,−],F) ≅ Π_s F(P_s)` holds at the level of
enriched hom-*objects* for every closed base (that is real and useful), but the *embedding
into enriched endofunctors is full and faithful for no nontrivial effect*. The obstruction
is uniform: closedness needs a terminal object (`M⊤≅1`); connectedness needs `M` to preserve
`∐` (writer form + `M∅=∅`); the two together pin `M=Id`. The "preferable enriched setting"
does not rescue uniform f&f — it relocates the same obstruction (non-codensity in the
ordinary picture; disconnected unit here) but does not remove it.

**Design consequence for agentic-AI containers:** there is *no* effect monad `M` over which
one can build change-of-base containers `Fam(Kl(M)^op)` and retain a uniform full-and-
faithful self-enriched semantics. Any nontrivial effect must be carried either by the
always-ff **Kleisli-presheaf** embedding (B) (paying the price that its transformations are
Kleisli-natural, not pure-natural) or by the ordinary `[Set,Set]` extension (A) with the
codensity monad `Ran_M M` measuring the fullness defect. Enrichment is a *reformulation*
tool, not a *fix*.

## Gaps / caveats (precisely stated)

1. **Copowers vs. all coproducts (inherited from T1, does NOT affect this theorem).** T1's
   *necessity* is proved via the copower test; whether it upgrades to "preserves all small
   coproducts" in every closed base is an open gap in T1 (`fullness-unit-connectedness.md`,
   "Open gap"). Here it is *irrelevant*: Step 1 uses only copower-preservation (`T·1`), and
   already forces the writer form, so every non-`Id` member of `𝒞ℒ` fails even the copower
   test and is therefore not full by the *proved* half of T1-necessity. The classification
   `{Id}` stands on the copower test alone.

2. **Finite- vs. small-coproduct reading of `𝒰𝒩`.** With the paper's definition (small
   coproducts, P5) the theorem is complete. If one weakened `𝒰𝒩` to *finite* coproduct
   preservation, Step 1's writer form (★) would hold only for finite `T`, and Step 2 would
   still give `M1≅1` and `Mn≅n` for finite `n`, but the behaviour of `M` on infinite sets
   would not be pinned by finite coproducts alone. I did not close whether a commutative,
   closed, `M1≅1`, finite-coproduct-preserving monad differing from `Id` on infinite sets
   can exist; I conjecture not (closedness of `Kl(M)` should propagate), but flag it as the
   one open question if the definition is weakened. Under the actual T1 definition there is
   no gap.

3. **Scope.** The classification is for commutative strong monads on `Set` (the domain where
   `Kl(M)` is symmetric monoidal, Kock). Non-commutative `M` give only premonoidal `Kl(M)`,
   where construction (C) is not even available; they are outside TARGET a fortiori.
